# Real domain catalog source

`real_domains.txt` is a filtered snapshot of the **Majestic Million** public
domain ranking:

- source: https://downloads.majestic.com/majestic_million.csv
- downloaded: 2026-10-27
- filtered to the game zones `.com`, `.ru`, `.io`, `.xyz`
- 100 500 unique registered domain names
- names are stored one per line

The names are used as **virtual game cards**. The project does not sell,
register, transfer or claim ownership of any real domain. Prices and rarity in
the game are fictional values and are not related to the market value of the
real names.

Please review Majestic's current terms and attribution requirements before
using this list in a commercial product.
